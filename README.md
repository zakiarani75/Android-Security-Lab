# Android Security & Penetration Testing Lab

📱 Android WAN Connectivity & Payload Testing using Kali Linux, Ngrok, and Metasploit.

---

## ✨ Benefits
- Learn Android penetration testing workflow
- Understand WAN connectivity setup
- Practice Metasploit listener configuration
- Test payload deployment in a lab environment
- Improve cybersecurity and ethical hacking skills

---

## 🛠 Tools Used
- Kali Linux
- Ngrok
- Metasploit Framework
- MSFVenom
- Android Device

---

## 🚀 Project Setup

### 1️⃣ Network Tunneling
Created a public WAN connection using Ngrok TCP tunnel.

### 2️⃣ Payload Generation
Generated Android APK payload using MSFVenom.

### 3️⃣ Listener Setup
Configured Metasploit multi-handler on Port 80.

### 4️⃣ Testing
Installed and executed the APK on Android device for security testing.
